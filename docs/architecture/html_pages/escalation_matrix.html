📋 Escalation Rules

  • Automatic escalation if issue unresolved >2 agent days
  • Skip levels for critical issues (budget, strategic, malfunction)
  • Document all decisions in the database for audit trail
  • Notify all stakeholders when escalation occurs
  • Human gets final say on all major decisions
