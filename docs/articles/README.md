## Writing Style Guide

All articles follow the Nicanor Korir voice:

- **Conversational and friendly** - Talk to readers like developers over coffee
- **Practical over theoretical** - Always include concrete examples
- **Honest reflection** - Share mistakes and what was learned
- **Technical substance** - Go deep on one idea, don't skim
- **Clear takeaways** - End with actionable insights

**Avoid**: Generic advice, excessive bullet points, corporate speak, buzzword soup

**Include**: Personal anecdotes, real code/architecture examples, relatable analogies
